# CREDITS & ASSET DISCLOSURE

## 🎨 Asset Generation Disclosure
All 3D models, geometries, textures, materials, and audio effects in **CoverUp** are generated 100% programmatically in code at runtime:
- **3D Geometries**: Procedural Three.js primitive assemblies (`BoxGeometry`, `CylinderGeometry`, `PlaneGeometry`, `ConeGeometry`).
- **Textures**: Generated dynamically using HTML5 2D Canvas context rendering (wood grain, tile grid, wallpaper, blood stains, TV animation).
- **Audio & Sound Effects**: Synthesized completely using the browser Web Audio API (oscillators, noise buffers, biquad filters, dynamic stereo panners).
- **No external downloads, no paid assets, and no third-party media files were used.**
